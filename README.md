# 스크랩 스파이 (Scrap Spy)

적군 로봇 군단에 숨어든 최하급 작업 드론이 되어, 기지마다 목표를 한 방에 암살하고
뜯어낸 부품을 몸에 달아 점점 높은 계급으로 위장해 가는 탑다운 픽셀 잠입 게임이에요.

## 실행

가장 쉬운 방법: `dist/scrap-spy.html` 하나만 브라우저로 열면 돼요 (JS·CSS·폰트가 모두 들어 있어요).
소스를 고친 뒤엔 `node tools/bundle.mjs`로 다시 묶어요.

개발할 땐 ES 모듈이라 로컬 서버로 열어요.

```bash
python3 -m http.server 8765     # 또는 npx serve
# 브라우저에서 http://localhost:8765
```

## 조작

| 키 | 동작 |
|---|---|
| WASD / 방향키 | 이동 |
| Shift | 대시 (재충전 필요, 보는 눈 앞에서 하면 의심받아요) |
| Space | 암살 (사거리 안 적, 경계 중인 적은 뒤에서만) |
| E | 사물함 숨기 / 잔해 해체(길게) / 단말기 해킹(길게) |
| Esc | 일시정지 · M 소리 끄기 |

## 핵심 규칙

- **위장 계급** = 장착한 머리·몸통·팔·다리 4개 부품의 평균 계급. 바닥 테두리 색이 구역 등급이에요.
  내 계급보다 높은 구역에서 적 시야(손전등)에 걸리면 의심 게이지(`?`)가 차오르고, 다 차면 경보(`!`).
- **암살**은 한 방. 하지만 다른 적이 보면 즉시 경보, 폭발음은 근처 적을 불러와요.
- **잔해 해체**: 쓰러진 로봇을 길게 해체하면 부품 하나를 고를 수 있고, 잔해도 사라져서 발각을 막아요.
  부품 계급 차이가 너무 크면(3 이상) "어색한 조합"이라 가까이서 의심받아요.
- **경보**: 숨거나 시야에서 벗어나 7초(사물함 4초) 버티면 추적이 끊기고 다시 위장 상태가 돼요.
- **아지트**: 크레딧으로 업그레이드, 보관한 부품으로 교체.

## 스테이지

1. **녹슨 주조 공장**: 용광로와 컨베이어, 작업 드론과 경비 로봇. 목표는 공장 감독관
2. **극지 냉동 연구소**: 냉각 탱크, 회전 감시 카메라, 해킹 단말기. 목표는 수석 연구원
3. **네온 사령탑**: 홀로그램, 깜빡이는 레이저 게이트, 엘리트 근위대. 목표는 총사령관

## 구조

```
src/engine/fx.js          픽셀 FX 코어: color/light 두 버퍼, 페인터, Bayer 디더, 조명 합성
src/engine/particles.js   높이(z)가 있는 탑다운 파티클: 스파크, 연기, 파편, 불씨
src/engine/audio.js       WebAudio 합성 효과음
src/fx/effects.js         게임 전용 이펙트 (암살 베기, 로봇 폭발, 해체, 장착, 계급 상승, 경보, 탈출 빔 ...)
src/game/parts.js         부품/로봇 정의와 절차적 스프라이트 합성
src/game/world.js         타일맵, 충돌, 시야, 길찾기, 테마별 타일 아트, 정적 조명
src/game/stages.js        3개 기지 맵·순찰·카메라 데이터
src/game/mission.js       잠입 한 판의 모든 규칙과 렌더링
src/main.js               화면 전환, HUD, 아지트, 저장
tools/                    이펙트 컨택트 시트, 맵 검증, 자동 플레이 테스트 (Playwright)
```

이펙트는 [pixelfx](https://github.com/patch-gg/pixelfx) 스킬의 방법(초안 → 렌더 → 보고 → 다듬기,
color + light 두 버퍼, 선과 빛 위주, 히트스톱)을 따라 이 게임용으로 새로 만들었어요.
이펙트 확인: 서버를 띄운 뒤 `node tools/contact.mjs records/stab.png "fx=stab&victim=guard"`.

폰트: [Galmuri](https://github.com/quiple/galmuri) (SIL OFL 1.1, `assets/fonts/OFL.md`).
